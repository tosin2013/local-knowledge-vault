# windows cmds core 2

ipconfig /all, /release, /renew, /flushdns
ping, tracert, pathping
nslookup - DNS lookup
netstat - open connections/ports
chkdsk /f /r - fix disk errors
sfc /scannow - repair system files
DISM - repair Windows image (run before sfc if sfc fails)
gpupdate /force - reapply group policy; gpresult /r - show applied policies
diskpart - partitions
format, robocopy (robust copy), xcopy
shutdown /r /t 0
net use - map drive; net user - accounts
winver - Windows version
tools: msconfig, taskmgr, eventvwr, devmgmt.msc, diskmgmt.msc, services.msc, regedit, perfmon, resmon
